# Historiske luftfotos af Nældevej 42

Hentet 11. oktober 2026 fra Esri World Imagery Wayback (https://livingatlas.arcgis.com/wayback/), zoomniveau 18 (ca. 0,33 m pr. pixel), 4 × 4 fliser om adressepunktet 57,027092 N, 9,807568 Ø.
