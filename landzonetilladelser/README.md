# Arkiv: landzonetilladelser, vi sammenligner os med

Hentet 10. oktober 2026. Afgørelserne fra Aalborg Kommune er hentet fra Plandatas register over landzonetilladelser (lag `pdk:theme_pdk_landzonetilladelse_vedtaget_v`); linket i sidste kolonne er den offentlige kilde. Afstanden er målt fra den nye hals midte.

Hvad vi har lært af dem, står i [../docs/ansoegning-gaps.md](../docs/ansoegning-gaps.md), afsnittet "Sammenligning med godkendte sager".
